# Tests

## test_telegram_final.py

Comprehensive Telegram bot test that:
- Verifies bot token is valid
- Checks webhook status
- Gets chat_id from recent messages
- Tests sending messages with different formats
- Waits for user message and replies

**Usage:**
```bash
python tests/test_telegram_final.py
```

Send a message to your bot while the test is running to verify everything works.
